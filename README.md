# Usta by Bekmetov — платформа для мастеров

Ядро платформы: сервер и база данных. Приложение мастера (Telegram mini-app, позже iOS/Android) и админка BGP подключаются к этому серверу через API.

## Что уже работает

- **Вход мастера** по номеру телефона и SMS-коду (+7 Казахстан, +998 Узбекистан). Телефон — главный ключ мастера, поэтому переход с Telegram на своё приложение ничего не теряет.
- **Коды:** загрузка файла кодов от Asian Paints (CSV `code,sku`), генерация своих случайных 14-значных кодов, выгрузка для печати наклеек.
- **Отгрузка:** склад отмечает отгруженные коды и дилера — только после этого коды начисляют баллы.
- **Скан:** QR (в том числе ссылка с кодом) или ручной ввод 14 цифр. Баллы = объём × баллы за литр/кг × акция. +100 приветственных за первый скан.
- **Баллы:** журнал без удалений, удержание 3 дня перед обменом, сгорание через 12 месяцев (сначала самые старые), уровни Старт / Бронза / Серебро / Золото по заработанному за 12 месяцев.
- **Награды:** каталог, обмен, ограничение по уровню и остатку, заявки (ожидает → одобрено → выполнено, или отклонено с возвратом баллов).
- **Антифрод:** неактивированный код, чужой код, дневной лимит, всплеск сканов (заморозка до проверки), подбор кодов вручную (блокировка ввода на сутки), блокировка мастера. Обмен закрыт, пока проверка открыта.
- **Админка (API):** роли admin / marketing / warehouse / finance, дашборд (доля сканов от отгруженного по дилерам, продукты, города, обязательства по баллам), журнал всех действий сотрудников.

## Запуск для разработки

```bash
pip install -r requirements.txt
python -m app.cli seed-demo                                   # демо-продукты SmartCare, дилер, награды
python -m app.cli create-admin admin@bgp.kz "Имя" "надёжный-пароль"
uvicorn app.main:app --reload
```

Документация API с кнопками для проверки: http://localhost:8000/docs
В режиме разработки (`DEBUG=1`) SMS не отправляется, код приходит в ответе API.

Тесты: `python -m pytest`

## Настройки (.env на сервере)

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | `postgresql+psycopg://user:pass@host/usta` |
| `JWT_SECRET` | длинная случайная строка, от 32 символов |
| `DEBUG` | `0` на сервере |
| `POINTS_HOLD_DAYS`, `POINTS_TTL_DAYS`, `WELCOME_BONUS` | правила баллов |
| `MAX_SCANS_PER_DAY`, `BURST_MAX_SCANS`, `BURST_WINDOW_MINUTES`, `MANUAL_FAIL_LIMIT` | антифрод |

Сгорание баллов: раз в сутки `python -m app.cli expire-points`.

## Структура

```
app/
  models.py           таблицы: мастера, продукты, дилеры, коды, отгрузки, баллы, награды, фрод, сотрудники, журнал
  services/codes.py   загрузка, генерация, отгрузка, скан + антифрод
  services/ledger.py  баланс, удержание, уровни, сгорание
  services/rewards.py обмен, заявки, решения по фроду
  api/auth.py         вход мастера
  api/master.py       API приложения мастера
  api/admin.py        API админки
  security.py         пароли, токены, телефоны, проверка Telegram initData
  sms.py              отправка SMS (сейчас заглушка)
tests/                весь путь банки и сценарии фрода
```
