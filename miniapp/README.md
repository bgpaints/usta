# Usta — приложение мастера (Telegram Mini App)

React + Vite. Работает внутри Telegram и в обычном браузере (без камеры — только ручной ввод кода).

## Экраны
Приветствие → вход по телефону и SMS → профиль (имя, город, специализация) → главная (баланс, уровень, последние начисления) → скан (встроенный QR-сканер Telegram) или ручной ввод 14 цифр → результат → история → награды и обмен → профиль с заявками.

## Запуск для разработки
```bash
# в корне проекта: сервер на порту 8000
uvicorn app.main:app --reload
# здесь:
npm install
npm run dev        # http://localhost:5173, запросы /api уходят на сервер
```

## Сборка
```bash
VITE_API_URL=https://api.ustaclub.kz npm run build   # адрес сервера — когда будет домен
```
Папку `dist/` выкладываем на хостинг по HTTPS, адрес указываем в @BotFather → Bot Settings → Menu Button / Web App.

## Telegram
- `src/telegram.ts` — сканер QR, вибрация, кнопка «Назад», подтверждения.
- Камера работает только внутри Telegram (версия 6.4+).
